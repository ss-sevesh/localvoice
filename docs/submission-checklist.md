## Verification and practical limits

Fresh verification passed **54 backend tests, 20 frontend tests, all 12 Chrome
scenarios** (including real-model voice flows), Ruff, ESLint, TypeScript, and the production build.
The latest 30-turn timing run measured **3,499 ms median / 5,406 ms p95** and **missed
the internal ≤3s / ≤5s budget**. This remains a performance limitation; the assignment
does not specify a numerical latency cutoff. [Raw results](benchmark-current.json),
[review and verification](review.md), and [performance analysis](performance.md)
preserve the failed budget status alongside the passing functional checks.

The demonstration verifies six actual speech turns, 138 text deltas, 13 browser audio
buffers and one playback stop. Both original and faster encoded MP4s were checked
for recognizable English/Hindi questions and replies. Name recall demonstrates
session context. The demo recorder rejects missing transcripts, streaming, playback,
interruption, or memory evidence before export.

The supplied assignment does not require a cloud deployment, paid services, or a
human-recorded microphone input. Synthetic input is disclosed rather than presented
as a human recording. Naturalness with a particular accent, noisy room, or headset
still needs human listening and microphone testing. The small language model can
make factual mistakes; these checks do not establish general answer accuracy.

The current 30-turn results apply to the GPU configuration. A clean installation
on a separate machine was not performed during this audit. Model/data licenses are
documented separately; the Piper Hindi voice used for synthetic inputs has
noncommercial dataset terms and is not used for assistant replies.

The requested timeline is 4–5 days. Repository history begins on 2026-10-17; the
assignment receipt date is not available here, so the submission deadline cannot be
independently verified. The repository and videos are ready to include in a submission;
this audit does not send them to Trikon.
